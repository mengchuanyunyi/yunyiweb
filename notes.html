容易混淆的拼音

先找动作差异，再用成组词语固定听觉。每组都可以进入对应的发音专题继续练。

前后鼻音an / ang · en / eng · in / ing · eng / ong

区别在最后的收音位置：前鼻音用舌尖，后鼻音用舌根靠近软腭。

平舌与翘舌z / zh · c / ch · s / sh

平舌时舌尖靠近上齿背；翘舌时舌尖向后抬，不要只靠“卷舌”想象。

鼻音与边音n / l

n 让气流经过鼻腔；l 的气流从舌头两侧通过。

唇齿与舌根f / h

f 用上齿接近下唇；h 在口腔后部形成摩擦，嘴唇不咬合。

送气与不送气b / p · d / t · g / k · j / q · z / c · zh / ch

不是“清浊”或音量大小，而是气流强弱与爆发时机不同。

易混韵母与拼写u / ou · ie / üe · i / ü · y / w

先看圆唇和舌位，再区分实际读音与拼写规则；j、q、x、y 后的 ü 省写两点。

常见易错多音字

HOW TO READ / 多音字判断方法

先看三件事

下面的标注是判断线索，不用背术语；碰到固定词时，仍以词语读音为准。

词义
这个字在词里表示什么意思？意思变了，读音也可能变。
词性 / 语法功能
它是在表示动作，还是在给人、事物、地方命名？
语体（文读 / 语读）
它常用于正式词语，还是日常口语？
和hé / hè / huó / huò / hú

hé最常用

和谐、和平、和气、我和你

表示协调、温和，或作连词连接并列成分。

hè应和

附和、唱和、曲高和寡、一唱一和

表示声音相互响应，或跟着别人的意见说。

huó揉成一体

和面、和泥、和粉

把粉状物加水搅拌、揉弄，使它有黏性。

huò掺合

和药、和稀泥、和弄

把粉末、颗粒或不同东西掺在一起。

hú固定用法

和牌

麻将中达到规定组合而获胜；使用范围较窄。

通俗判断“和谐、和谁一起”读 hé；跟着声音响应读 hè；揉面团读 huó；把东西掺合读 huò；麻将获胜读 hú。在“暖和”里，“和”通常读轻声 huo。

蔓màn / wàn / mán

wàn词义 · 名物

藤蔓、瓜蔓

指细长、能缠绕的茎，像是在给植物的“藤条”命名。“藤蔓”常读 téngwàn，téngmàn 也见于规范使用，不宜一概判错。

màn语体 · 文读

蔓延、蔓生、蔓草

多出现在书面复合词里，常带有延伸、生长的意思。

mán固定词

蔓菁

只需把它当作这个植物名称的固定读法。

通俗判断说植物的藤条，可以先想到 wàn；说“向外扩散”，通常读 màn。遇到“藤蔓”，要知道两种读法都有依据。

血xuè / xiě

xuè语体 · 文读

血液、血压、贫血、心血

常用于结合紧密的正式复合词、医学词和成语。

xiě语体 · 语读

流了点儿血、吐了一口血、鸡血

多在口语里单独说，或出现在少数生活常用词中。

通俗判断“血液”是一个完整词，读 xuè；“伤口流了点儿血”里的“血”更像单独说出来，读 xiě。这主要不是词性变化，而是正式表达和日常口语的区别。

薄báo / bó / bò

báo语体 · 语读

纸很薄、薄饼、薄片

口语里直接说厚度小，或用于日常事物。

bó语体 · 文读

薄弱、单薄、淡薄、厚此薄彼

常在书面复合词里表达力量弱、数量少或感情不深。

bò固定词

薄荷

这个读音主要记住“薄荷”即可。

通俗判断能直接用手感受到“很薄”，多读 báo；抽象地说“薄弱、淡薄”，多读 bó。

处chǔ / chù

chǔ词性 · 动词

处理、相处、处罚、处于

表示处理、交往、处在某种状态等动作或状态。

chù词性 · 名词

住处、好处、办事处、处所

给地方、部位、单位或某种结果命名。

通俗判断能回答“在做什么”，多读 chǔ；能回答“什么地方、什么单位”，多读 chù。

角jiǎo / jué

jiǎo词义 · 形体

角度、墙角、牛角、三角形

和角落、形状、动物的角或计量单位有关。

jué词义 · 人物 / 竞争

角色、主角、名角、角逐

指戏剧人物、演员身份，或彼此竞争。

通俗判断看得见、量得出的“角”，多读 jiǎo；人物和竞争中的“角”，多读 jué。

模mó / mú

mó词义 · 规范 / 仿效

模型、模式、模范、模仿

表示标准、样板、仿照或抽象的结构方式。

mú词义 · 外形 / 工具

模样、模子、模具、一模一样

指具体的外形，或用来定型的器具。

通俗判断抽象的样板和方法多读 mó；具体的样子和模具多读 mú。

强qiáng / qiǎng / jiàng

qiáng词义 · 强大

强大、坚强、增强、强烈

表示力量大、程度高或能力好。

qiǎng词义 · 勉强

强迫、强求、勉强、强词夺理

带有硬要、迫使或不情愿去做的意思。

jiàng词义 · 固执

倔强、强嘴、脾气强

形容固执、不肯服软；常见于少数固定说法。

通俗判断有力量读 qiáng；硬逼着做读 qiǎng；性子固执读 jiàng。

差chā / chà / chāi / cī

chā词义 · 差别

差别、误差、时差、差异

表示两个事物之间不相同或有距离。

chà词义 · 不足

很差、差点儿、差不多、还差一个

表示不好、不够，或距离目标还缺一点。

chāi / cī固定用法

出差、差事 / 参差不齐

chāi 与派遣、差事有关；cī 主要记住“参差”。

通俗判断“不同”读 chā，“不够好”读 chà，“被派去办事”读 chāi。

泊bó / pō

bó词义 · 停留

停泊、漂泊、淡泊

表示船停靠、人在外辗转，或不追逐名利。

pō词义 · 水面

湖泊、水泊、血泊

指湖或大片积水；“血泊”表示大摊的血。

通俗判断“停在哪里”读 bó；“一片水”读 pō。

冠guān / guàn

guān词性 · 名物

皇冠、衣冠、树冠、冠心病

原指帽子，也用于外形像帽子的顶部。

guàn词义 · 居首

冠军、夺冠、冠名、冠绝一时

表示戴上、位居第一或把名称加在前面。

通俗判断帽子和顶部读 guān；拿第一、加名号读 guàn。

累lèi / lěi / léi

lèi词义 · 疲劳

劳累、疲累、累人、累坏了

表示辛苦、疲劳，或使别人辛苦。

lěi词义 · 积累 / 牵连

积累、累计、连累、日积月累

表示一层层增加，或把别人牵连进去。

léi固定用法

累赘、果实累累

常见于“多而成串”或“多余、拖累”的固定说法。

通俗判断身体疲劳读 lèi；越积越多或牵连别人读 lěi；“累赘”单独记 léi。

载zǎi / zài

zǎi词义 · 记录 / 年

记载、登载、刊载、三年五载

表示写入记录，或表示“年”。

zài词义 · 承载

载客、装载、满载、载歌载舞

表示装上、承担，或“一边……一边……”。

通俗判断写进资料或数年份读 zǎi；车船装东西读 zài。

着zhe / zháo / zhuó / zhāo

zhe语法功能 · 状态

看着、放着、笑着、沿着

轻声，表示动作正在持续或某种状态存在。

zháo词义 · 得到结果

睡着、着火、着凉、找着了

表示接触到、受到影响，或动作有了结果。

zhuó / zhāo书面 / 固定用法

着手、着重、着陆 / 高着、失着

zhuó 多见于正式复合词；zhāo 指棋步、办法。

通俗判断跟在动作后面常读轻声 zhe；动作“成了”常读 zháo；“着手、着重”读 zhuó。

结jié / jiē

jié词义 · 连接 / 结束

结合、结婚、总结、团结

表示连接、形成关系，或事情收束。

jiē词义 · 生长 / 凝实

结果子、结实、结巴

用于植物长出果实，以及少数固定口语词。

通俗判断大多数复合词读 jié；植物“结果”、东西“结实”和“结巴”读 jiē。

创chuàng / chuāng

chuàng词义 · 创造

创造、创新、创业、首创

表示第一次做出、建立新的事物。

chuāng词义 · 伤口

创伤、重创、创口

表示身体或心理受到伤害。

通俗判断做出新的东西读 chuàng；受了伤读 chuāng。

塞sāi / sè / sài

sāi词义 · 填入

塞进去、瓶塞、塞车、活塞

表示把东西填进空隙，或指堵口的物件。

sè词义 · 堵住

堵塞、闭塞、阻塞、茅塞顿开

多用于正式复合词，表示不通、不开放。

sài词义 · 边地

边塞、要塞、塞外

指边境上可作屏障的险要地方。

通俗判断动手把东西“塞进去”读 sāi；道路、思想“不通”读 sè；边境关口读 sài。

露lù / lòu

lù语体 · 文读

露水、暴露、揭露、崭露头角

常用于结合紧密的书面复合词。

lòu语体 · 语读

露脸、露馅、露马脚、露一手

多见于日常口语，表示显出来、被发现。

通俗判断正式说“暴露、揭露”读 lù；口语说“露脸、露馅”读 lòu。

行xíng / háng

xíng词义 · 行动 / 可以

行走、行动、执行、可行

表示走、做、实施，口语里也可表示“可以”。

háng词义 · 行列 / 行业

银行、行业、同行、行列

表示成排的次序、职业门类或营业机构。

通俗判断表示去做、能不能做读 xíng；表示行业和一排读 háng。

假jiǎ / jià

jiǎ词义 · 不真实 / 假设

真假、假装、假如、弄虚作假

表示不真实，或先设定一种情况。

jià词义 · 休息时间

请假、放假、假期、休假

表示按规定暂时离开工作或学习。

通俗判断不是真的读 jiǎ；不上班、不上课的假期读 jià。

教jiāo / jiào

jiāo词义 · 传授

教书、教唱歌、教孩子识字

直接表示把知识或技能传给别人。

jiào词义 · 教导 / 教育体系

教育、教师、请教、宗教

常用于结合紧密的复合词，也可表示教导和求教。

通俗判断句子里直接说“教某人做某事”常读 jiāo；“教育、教师、请教”读 jiào。

禁jīn / jìn

jīn词义 · 承受 / 忍住

禁得住、不禁、弱不禁风、忍俊不禁

表示经受得住，或控制不住某种反应。

jìn词义 · 禁止

禁止、严禁、禁区、违禁品

表示不准许，或不允许进入、使用。

通俗判断能不能承受、忍不忍得住读 jīn；规则不准做读 jìn。

铺pū / pù

pū词性 · 动词

铺路、铺开、铺床、铺天盖地

表示把东西展开、摊平或布置开。

pù词性 · 名词

店铺、床铺、商铺、铺位

表示商店、床位或可供使用的位置。

通俗判断正在展开东西读 pū；一个店或一张床位读 pù。

数shǔ / shù / shuò

shǔ词性 · 动词

数数、数一数、数得上、数不胜数

表示一个一个计算，或列举、比较。

shù词性 · 名词

数字、数量、数学、次数

表示数目、数量或相关概念。

shuò固定书面用法

数见不鲜

表示屡次、频繁；现代常用词中范围很窄。

通俗判断正在点数读 shǔ；“数字、数量”读 shù；shuò 记住“数见不鲜”。

转zhuǎn / zhuàn

zhuǎn词义 · 改变方向

转弯、转身、转变、转告

表示方向、状态或信息发生转换。

zhuàn词义 · 旋转 / 绕行

转圈、转动、旋转、转速

表示绕着中心运动，或计算旋转的速度。

通俗判断从一个方向变到另一个方向读 zhuǎn；绕着中心不停转读 zhuàn。

重zhòng / chóng

zhòng重量 / 程度

重量、重要、严重、尊重

表示分量大、程度深或看重。

chóng重复 / 层次

重新、重复、重叠、重阳

表示再来一次或一层叠一层。

通俗判断分量和程度读 zhòng；“再一次、叠一层”读 chóng。

长cháng / zhǎng

cháng长度 / 长久

长短、长江、长远、擅长

表示长度、时间久或某方面做得好。

zhǎng生长 / 长辈

长大、成长、校长、家长

表示生长，也用于负责人和辈分较高的人。

通俗判断问“有多长”读 cháng；问“谁长大、谁负责”读 zhǎng。

朝cháo / zhāo

cháo方向 / 朝代

朝向、朝南、唐朝、朝代

表示面对某个方向，或历史上的政权时期。

zhāo早晨

朝阳、今朝、一朝一夕

表示早晨或一天开始的时候。

通俗判断方向和朝代读 cháo；“早晨”这层意思读 zhāo。

还hái / huán

hái副词

还有、还是、还好、还没

表示仍然、更加或补充说明。

huán归还 / 回报

还书、归还、偿还、还礼

表示把东西送回去，或给予回报。

通俗判断能换成“仍然、另外”读 hái；把东西还回去读 huán。

便biàn / pián

biàn便利 / 就

方便、便利、随便、便于

表示便利，也可表示“就、即”。

pián价低 / 得利

便宜、占便宜、大腹便便

常见于价钱低、得到额外好处等固定说法。

通俗判断“方便”读 biàn；“便宜”及相关说法读 pián。

为wéi / wèi

wéi成为 / 做

成为、认为、行为、以为

表示做、成为、判断或看作。

wèi目的 / 对象

为了、因为、为你、为何

表示目的、原因，或动作所面对的对象。

通俗判断能换成“做、成为”读 wéi；能换成“为了、给”读 wèi。

更gèng / gēng

gèng程度增加

更加、更好、更快、更进一步

表示程度在原有基础上继续增加。

gēng改变 / 夜更

更改、更新、更正、三更

表示改变、替换，或旧时夜间计时单位。

通俗判断“更加”读 gèng；“改换、更新”读 gēng。

乐lè / yuè

lè快乐 / 喜爱

快乐、乐观、乐意、其乐无穷

表示高兴、喜爱或愿意。

yuè音乐

音乐、乐器、乐曲、声乐

表示有组织的声音和相关艺术。

通俗判断心情高兴读 lè；与音乐、乐器有关读 yuè。
